# MOOD.LY

## An Intelligent Text Emotion Detection and Analysis System

Moodly is a machine learning project that detects the emotion expressed in a given piece of text.

### Planned Technologies

- Python
- DistilBERT
- Hugging Face Transformers
- Scikit-learn
- Gradio

### Emotions

The model will classify text into different emotion categories and provide the predicted emotion with confidence scores.
